# MSc Energy Infrastructure

Starter materials for the MSc Energy Infrastructure course. The repository contains teaching notebooks, supporting datasets, and exploratory examples covering circuit analysis, power flow, network modelling, and energy-system optimisation.

## Getting started

1. Fork or 'Use this template' to create your own copy of the repository. You can then clone your copy to your local machine and make changes without affecting the original repository.
2. Clone or download the repository.
3. Create a Python environment using the `environment.yml` file. This will install all the required dependencies for the notebooks.

   ```bash
   conda env create -f environment.yml
   conda activate GeoPower
   ```

4. Open a notebook from StarterNotebooks when instructed to do so in the course. You can run the notebooks in JupyterLab or VSCode.
